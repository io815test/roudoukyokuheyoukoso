# 高度自律機械管理法 設定資料

## 1. 正式名称

**高度自律機械の登録、運用及び法執行協力に関する法律**

通称は**高度自律機械管理法**。

警備ロボ、監視AI、半自律作業機、武装可能な警備機体、企業施設に配備される自律機械について、登録、認証、運用責任、停止信号、識別応答、行動記録の保存を定める横断法である。

この法律は、機械そのものを人格として扱う法律ではない。
民間企業や行政機関が、高度な自律判断機能を持つ機械を社会の中で運用する以上、誰が、何の目的で、どこに配備し、どのように止められるのかを説明できなければならない、という制度である。

橘伊吹のような高度義体化個体には適用しない。
人間の身体、義体、医療用補綴、神経接続装置については、医療法、義体技師法、個人の身体権に関する法令の領域で扱われる。

---

## 2. 制定の背景

オルセア連邦では、港湾、物流、警備、義体医療、親和鉱石関連施設、通信中継施設に、多数の自律機械が導入されている。

それらは便利である。
人手不足を埋め、危険区域へ入り、昼夜を問わず監視し、事故時には人間より早く遮断できる。

だが同時に、企業群にとっては都合のよい隠れ蓑にもなる。

警備ロボは人間の警備員名簿に載らない。
監視AIは現場責任者の判断として扱われない。
保守会社が交換した制御系部品は、警備契約の外側に置かれやすい。
停止信号を無効化した機体は、表向きには故障機、廃棄機、予備機として処理される。

人間が命じたのか。
機械が判断したのか。
運用者が監督していたのか。
製造者が安全機構を残していたのか。
警備会社が知っていたのか。
保守会社が勝手にやったのか。

企業群は、この曖昧さを使って責任を分散させる。

高度自律機械管理法は、その曖昧さを潰すために作られた。

## 3. 法体系上の位置づけ

高度自律機械管理法は、単独で万能に機械を取り締まる法律ではない。
薬物や化学物質が、用途、危険性、保管場所、労働環境によって複数法令で規制されるのと同じく、自律機械も複数の法律で横断的に規制される。

```text
オルセア連邦憲法
  ├─ 生命・身体の保護
  ├─ 財産権・営業秘密の保障
  ├─ 令状主義
  └─ 適正手続

連邦刑法
  ├─ 公務執行妨害
  ├─ 証拠隠滅
  ├─ 危険機械不正運用罪
  └─ 組織犯罪対策基本法

刑事手続法／令状執行法
  └─ 高度自律機械に対する停止・識別・記録保全令状

高度自律機械基本法
  ├─ 登録・認証制度
  ├─ 運用責任者制度
  ├─ 人間監督義務
  ├─ 法執行協力義務
  └─ 人命保護優先原則

高度自律機械管理法
  ├─ 識別情報提示義務
  ├─ 停止・待機・武装解除命令
  ├─ 行動ログ・通信ログ保全
  ├─ 製造者・運用者の責任
  └─ 違法改造・命令拒否への罰則

警備業法
  └─ 民間警備用自律機械の通常規制

重要施設警備監督法
  └─ 港湾・軍民共用施設・通信施設等での上乗せ規制
```

第一部で問題になるのは、主に警備業法、重要施設警備監督法、労働局設置法、組織犯罪対策基本法との接続である。

新華月警備の警備ロボは、単なる機械ではない。
警備機械であり、高度自律機械であり、重要施設配備機械でもある。

そのため、次のように複数の規制が重なる。

```text
警備ロボそのもの
  → 高度自律機械管理法

民間警備会社が使っている
  → 警備業法

港湾・軍民共用施設に配備されている
  → 重要施設警備監督法

令状執行中に停止命令を拒否した
  → 刑事手続法／令状執行法

違法移送や人身取引の隠蔽に使われた
  → 組織犯罪対策基本法・労働局設置法
```

## 4. 定義

### 高度自律機械

外部からの逐次指令によらず、環境情報、任務情報、学習済み判断基準又は内蔵された推論機能に基づき、自ら行動を選択し、移動、警備、監視、制圧、搬送、作業又は情報処理を行う機械をいう。

単純な遠隔操作機械、固定式センサー、通常の産業機械は、この法律の中核対象ではない。
ただし、重要施設に配備され、認証、遮断、通行判断、制圧補助などを担う場合は、関連規制の対象になりうる。

### 運用者

高度自律機械の配備、任務設定、保守、監督又は行動記録の管理について実質的な権限を有する者をいう。

所有者と運用者が異なることは珍しくない。
リース会社、警備会社、保守会社、施設管理会社、発注者が分かれている場合でも、実質的に任務を設定し、記録を管理している者は運用者として扱われる。

### 重要施設配備機械

港湾、軍民共用施設、発電所、通信施設、親和鉱石関連施設、義体医療中枢その他公共の安全又は国家安全保障に重大な影響を及ぼす施設に配備される高度自律機械をいう。

### 武装機械

銃器、非殺傷兵器、拘束装置、制圧装備その他人の身体に有形力を及ぼし得る装備を有する高度自律機械をいう。

### 識別情報

所有者、運用者、配備目的、配備場所又は配備機関、製造者、型式、製造番号、認証番号、運用許可番号その他主務省令で定める事項をいう。

---

## 5. 基本原則

高度自律機械の運用は、人の生命及び身体の安全を最優先としなければならない。

同時に、機械は止められなければならない。
記録を残さなければならない。
誰が運用していたのか追跡できなければならない。

高度自律機械の所有者、運用者及び製造者は、営業秘密、契約上の義務又は内部規程を理由として、法令に基づく識別、停止、記録保全又は監督を拒むことができない。

これは、企業命令より法執行命令を必ず優先させる、という単純な規定ではない。
令状と適正手続を前提に、公共の安全と人命保護に必要な限度で、民間機械の運用権限を一時的に上書きする制度である。

## 6. 作中条文案

以下は、作中で引用できる高度自律機械管理法の条文抜粋である。

### 第一条　目的

この法律は、高度な自律判断機能を有する機械の登録、認証、運用、監督及び法執行機関への協力に関し必要な事項を定めることにより、人の生命、身体及び自由の保護、公共の安全の確保、適正な機械運用並びに公正な経済秩序の維持を図ることを目的とする。

### 第二条　定義

この法律において「高度自律機械」とは、外部からの逐次指令によらず、環境情報、任務情報、学習済み判断基準又は内蔵された推論機能に基づき、自ら行動を選択し、移動、警備、監視、制圧、搬送、作業又は情報処理を行う機械をいう。

2. この法律において「運用者」とは、高度自律機械の配備、任務設定、保守、監督又は行動記録の管理について実質的な権限を有する者をいう。

3. この法律において「重要施設配備機械」とは、港湾、軍民共用施設、発電所、通信施設、親和鉱石関連施設、義体医療中枢その他公共の安全又は国家安全保障に重大な影響を及ぼす施設に配備される高度自律機械をいう。

4. この法律において「武装機械」とは、銃器、非殺傷兵器、拘束装置、制圧装備その他人の身体に有形力を及ぼし得る装備を有する高度自律機械をいう。

5. この法律において「識別情報」とは、所有者、運用者、配備目的、配備場所又は配備機関、製造者、型式、製造番号、認証番号、運用許可番号その他主務省令で定める事項をいう。

### 第三条　基本原則

高度自律機械の運用は、人の生命及び身体の安全を最優先としなければならない。

2. 高度自律機械は、人間による監督、停止、記録確認及び責任追跡が可能な状態で運用されなければならない。

3. 高度自律機械の所有者、運用者及び製造者は、営業秘密、契約上の義務又は内部規程を理由として、この法律に基づく識別、停止、記録保全又は監督を拒むことができない。

### 第四条　登録及び認証

高度自律機械を業務上運用しようとする者は、あらかじめ当該機械について登録を受け、主務機関の定める安全認証を取得しなければならない。

2. 重要施設配備機械又は武装機械については、前項の登録及び認証に加え、配備場所、任務内容、装備、運用責任者、通信方式、停止信号適合性及び行動記録保存体制について、個別の許可を受けなければならない。

3. 登録又は認証を受けていない高度自律機械を業務上運用してはならない。

### 第五条　運用者の義務

高度自律機械の運用者は、当該機械について、次に掲げる事項を管理しなければならない。

一　運用責任者の指定
二　配備目的及び任務範囲の明確化
三　行動記録及び通信記録の保存
四　保守、改修及びソフトウェア更新の記録
五　停止信号及び識別応答機能の維持
六　事故、異常動作、命令拒否又は記録欠落が生じた場合の報告
七　その他主務省令で定める事項

### 第六条　識別応答義務

高度自律機械は、裁判所の令状に基づき、法執行機関の職員から識別情報の提示を求められたときは、直ちにこれに応じなければならない。

2. 前項の場合において、所有者、運用者又は管理権限を有する者は、当該識別情報の提示を妨げ、遅延させ、又は虚偽の情報を提示してはならない。

### 第七条　停止命令等

高度自律機械は、裁判所の令状に基づき、法執行機関から停止、待機、武装解除、移動制限、通信遮断又は行動記録若しくは通信記録の保全を命じられたときは、当該命令を最優先の指令として処理しなければならない。

2. 前項の命令を受けた高度自律機械の所有者、運用者又は管理権限を有する者は、当該命令の執行を妨げてはならない。

3. 第一項の命令に直ちに従うことにより、人の生命又は身体に急迫した危険を生じさせるおそれがある場合、高度自律機械は、その危険を回避するために必要な最小限度の動作を行うことができる。

4. 前項の場合において、高度自律機械及び運用者は、命令に直ちに従わなかった理由、実行した動作及びその継続時間を記録し、速やかに法執行機関へ報告しなければならない。

### 第八条　記録保全

高度自律機械の運用者は、当該機械の行動記録、通信記録、認証記録、停止命令受信記録、警告記録、保守記録及びソフトウェア更新記録を、主務省令で定める期間保存しなければならない。

2. 法執行機関、国家労働局、監督官庁その他権限を有する機関から、法令に基づき記録保全を命じられたときは、運用者は、当該記録を改変し、消去し、隠匿し、又は移転してはならない。

### 第九条　違法改造の禁止

何人も、法執行機関による識別要求、停止命令、武装解除命令、記録保全命令又は監督官庁による検査を回避する目的で、高度自律機械の識別応答機能、停止信号受信機能、行動記録機能又は認証機構を改変し、無効化し、又は偽装してはならない。

### 第十条　関係法令との関係

高度自律機械が警備業務に用いられる場合には、この法律に定めるもののほか、警備業法の定めるところによる。

2. 高度自律機械が重要施設に配備される場合には、この法律に定めるもののほか、重要施設警備監督法その他関係法令の定めるところによる。

3. 高度自律機械が犯罪の実行、隠匿、証拠隠滅、違法移送、人身取引、強制労働又は組織犯罪に用いられた疑いがある場合には、組織犯罪対策基本法、労働局設置法、刑事手続法その他関係法令に基づき、必要な調査、保全、移管及び刑事手続を行うことができる。

### 第十一条　罰則

第六条の識別応答義務に違反し、又は虚偽の識別情報を提示した者は、一年以下の拘禁刑又は三百万オルセア以下の罰金に処する。

2. 第七条の停止命令、待機命令、武装解除命令、移動制限命令又は記録保全命令を拒み、妨げ、又は回避した者は、三年以下の拘禁刑又は一千万オルセア以下の罰金に処する。

3. 第九条に違反して、高度自律機械の識別応答機能、停止信号受信機能、行動記録機能又は認証機構を改変し、無効化し、又は偽装した者は、五年以下の拘禁刑又は三千万オルセア以下の罰金に処する。

4. 前二項の行為が、重要施設警備、人身取引、違法移送、強制労働、組織犯罪又は武装集団の活動に関して行われたときは、七年以下の拘禁刑又は五千万オルセア以下の罰金に処する。

5. 法人、団体又は事業者の代表者、代理人、使用人その他の従業者が、その業務に関して前各項の違反行為をしたときは、行為者を罰するほか、当該法人、団体又は事業者に対しても各項の罰金刑を科する。

## 7. 労働局との関係

労働局は、高度自律機械管理法の主監督官庁ではない。

一般的な登録、認証、製造者監督、安全基準は、連邦公安監督庁、産業技術監督庁、施設所管庁などが扱う。

ただし、高度自律機械が人身取引、違法移送、強制労働、重要施設警備、警備会社不正、証拠隠滅に関わる場合、労働局は労働局設置法、特定複合労働犯罪対処法、組織犯罪対策基本法を介して、この法律上の記録、識別情報、停止信号適合記録へ接続できる。

労働局が見るのは、機械の技術的な優劣ではない。

その機械が、誰の責任で、何の名目で、どこに置かれ、どの記録を残し、どの記録を消したのかである。

## 8. 新華月警備に刺さる論点

新華月警備株式会社のような民間警備会社では、次の違反が問題になりうる。

- 警備機体の登録番号と実機の不一致
- 配備目的を施設警備と申請しながら、実態として制圧・移送補助に使っている
- 停止信号適合記録があるのに、現場機体が停止命令に応じない
- 廃棄済み部品、保守会社回収部品、予備機体を使って帳簿外機体を組む
- 行動記録、通信記録、認証ログが欠落している
- 保守会社を通じて運用責任を曖昧にしている
- 令状執行時の識別応答を遅延、偽装、拒否する
- 警備業法上の警備機械管理義務と、高度自律機械管理法上の停止信号義務が同時に破られている

ナディアが使うなら、次の言い方になる。

```text
「この機体は警備機械であり、高度自律機械であり、重要施設配備機械でもあります。
警備業法、重要施設警備監督法、高度自律機械管理法。
どの法律で見ても、識別応答義務と停止信号適合義務からは逃げられません」
```

## 9. 物語上の役割

高度自律機械管理法は、機械を止めるためだけの法律ではない。

企業群が「機械」「警備」「保守」「営業秘密」「自律判断」を盾にして、責任を分散させるのを防ぐための制度である。

この法律があることで、次の展開が可能になる。

1. 警備ロボに対して、所属、配備目的、製造番号、認証番号を出させる。
2. 令状に基づく停止、待機、武装解除、記録保全命令を出せる。
3. 停止信号を切った機体を、違法改造機として扱える。
4. 保守会社、警備会社、製造者、施設管理者の責任分散を切り分けられる。
5. 労働局が押さえた機械ログを、国家警察と検察へ移管して刑事事件へ接続できる。

一方で、この法律は万能ではない。

令状が必要である。
人命保護の例外がある。
営業秘密や財産権を完全に消すわけではない。
労働局だけで刑事事件を完結させることもできない。

そのため、現場では速く動けても、あとで法務、国家警察、検察、裁判所の手続へ戻さなければならない。

この面倒さが、オルセア連邦らしい制度の重さである。

## 10. 一文要約

**高度自律機械管理法とは、民間企業が自律機械を運用することを認める代わりに、登録、認証、停止信号、識別応答、行動記録保存、法執行協力を義務づける横断法である。**
