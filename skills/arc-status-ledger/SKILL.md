# Arc Status Ledger

Use this skill to keep long-arc continuity recoverable.

## Preferred Files

- Part 1: `drafts/reference/第一部_アーク概要.md`
- Part 2: `drafts/reference/第二部_適正処理済_企画メモ.md`
- Create `drafts/reference/第二部_アーク状況台帳.md` when the Part 2 draft becomes multi-episode.

## When Updating

Update the ledger after:

- a new episode draft is created
- a major scene is restructured
- a canon decision is made in conversation
- a new faction, law, weapon, or character becomes recurring
- a cliffhanger or unresolved thread is introduced

## Ledger Shape

Use compact sections:

- current timeline position
- confirmed facts
- unresolved threads
- character state changes
- institutional/legal state
- technical/worldbuilding decisions
- next episode handoff
- risks and contradictions to watch

## Rules

- Do not summarize the whole episode when only three facts changed.
- Separate confirmed text from planned intent.
- Mark uncertain decisions as `仮置き`.
- Prefer file links to source drafts or canon.
- Keep the ledger short enough to read at the start of a future session.

## Response Contract

After updating, report:

- ledger file changed or created
- key facts added
- open risks left unresolved
