# 第十三話　幕引き　プロット

## 役割

第一部の事件を、戦闘ではなく政治と責任の場で閉じる話。

排水ポンプ場、人質救出、湾内逃亡阻止は作戦としては成功した。しかし労働局は介入班一名を失い、多数の重軽傷者を出した。第十三話では、この損害をめぐって労働局が公的な説明責任を問われる。

ここで描くべきものは、単なる謝罪会見ではない。

* 労働局がなぜ独力で遅滞行動を選んだのか
* アルテミシアが組織の象徴として責任を引き受ける姿
* 橘が不在だったことを班長として受ける姿
* 金剛寺が現場指揮官として、作戦目的を「勝利」ではなく「逃亡阻止」と説明する姿
* レンシア通商連合評議会と、その影響下にある記者たちの攻撃
* それでも労働局が得た証拠と政治的成果
* アルテミシアの変質の兆候

最終的には「事件は幕を引いたが、労働局は無傷ではない」という後味にする。

## 前提整理

排水ポンプ場の戦闘と連動した作戦は終了した。

逃亡経路の大部分は潰され、証拠隠滅も完全ではないにせよ阻止された。人身売買に関わる帳簿、通信記録、搬送記録、協力企業の名簿、瑞海系勢力の国内協力者に関する断片が確保される。

一方で労働局強制介入班は壊滅的な損害を受ける。

* 立野隊員が死亡
* 重体一名
* 重軽傷者多数
* 排水ポンプ場で前線に出た隊員に無傷の者はいない
* しばらくまともな強制臨検を行える状態ではない

橘はヴェルフラードにいたため、排水ポンプ場の最終戦には参加していない。しかし強制介入班班長として、記者会見に出ないという選択肢はない。急遽帰国する。

会見には以下が出席する。

* アルテミシア・レイン　国家労働局総裁
* 法務部長　適法性、必要性、比例性の説明役
* 橘伊吹　強制介入班班長
* 金剛寺　排水ポンプ場での実働指揮官

## 敵対勢力

### レンシア通商連合評議会

首都レンシアを中心とする大企業群の利益調整団体。名目上は経済団体だが、実態としては物流、港湾、資源流通、警備、金融にまで強い影響力を持つ企業連合体。

国家機関の中にも縁の深い者がいる。上品に言えば縁が深い。実態としては抱き込まれている者も少なくない。

国家労働局は、そうした企業群の不正に手を入れるための機関である。そのため、レンシア通商連合評議会に近い者たちは、アルテミシアの労働局を目障りに思っている。

今回、強制介入班に死者と多数の負傷者が出たことは、彼らにとって格好の糾弾材料となる。

ただし、全面的に労働局を潰しには来ない。足かせは嵌めたいが、真っ向敵対はしない。

労働局が今回排除したのは、国内企業の縄張りを荒らす国外勢力でもある。瑞海系の人身売買網が本邦に橋頭堡を築けば、港湾、警備、物流、人材派遣の既存利権にも食い込んでくる。レンシア通商連合評議会にとっても歓迎できる話ではない。

そのため、攻撃には奇妙な歯止めがある。

* 死者を出した判断は責める
* 労働局の権限行使の危うさは問う
* しかし瑞海系勢力の排除そのものは否定しない
* 人身売買の構造には深く踏み込まない
* 既存企業群に火がつく質問は避ける

敵の敵は味方。

少なくとも、この件に限ってはそういうことになる。

### 記者たち

企業群と距離の近い記者が、会見で攻勢に出る。

彼らの狙いは真相ではなく、国家労働局の権限を削るための傷口を広げること。

質問の方向性は以下。

* 海上臨検隊や国防軍に任せるべきだったのではないか
* なぜ国家警察やCTRUの到着を待たなかったのか
* 労働局が強行したことで隊員を死なせたのではないか
* 介入班班長が不在の中で強行すべきではなかったのではないか
* アルテミシアの祈り、あるいは聖女の象徴性が現場判断を歪めたのではないか
* 強制介入班の権限を見直すべきではないか

# 記者からの地雷質問

### 橘班長は重要局面で不在だったようですが、危機管理が甘いのでは？海外出張とは暢気で……

* 祈りにより変質しつつあるアルテミシアは敵対ととらえ、雰囲気が変わる。

質問がアルテミシアの耳朶を打った時、彼女のそれまで纏っていた真摯ではあるが柔らかな空気が霧散したように質問者である記者には見えた。透明な氷のような澄んだ瞳が、わずかに細められる。記者は全身に鳥肌が立つように感じた。

## 話の流れ

### 1. 戦闘終了後の後始末

冒頭は戦闘終了後の事務処理から入る。

現場は国家警察、SAG、CTRU、水上臨検隊へ順次引き継がれる。労働局は証拠保全と負傷者搬送に追われる。排水ポンプ場は照明、血痕、破損した装備、薬莢、散乱した搬送ケースで戦闘の痕跡を残している。

立野の死亡が正式に確認される。

名前が報告書の一行になる瞬間を、アルテミシアが受け止める。ここで過度に泣かせない。むしろ感情が出せないことを描く。

ナディアや項は実務を進める。誰もアルテミシアを慰めない。慰める時間がない。

橘は国外から帰国の手配に入る。

### 2. 会見前

国家労働局本庁舎。

会見前の控室で、アルテミシア、法務部長、橘、金剛寺が最終確認を行う。

法務部長は説明の軸を確認する。

* 労働局の行動は完全制圧ではなく遅滞行動
* 国家警察は人質救出側へリソースを割いていた
* 海上臨検隊は湾内捜索と封鎖に動いていた
* 国防軍CTRUは要請から現着まで時間を要する
* 湾外母艦へ接続された場合、刑事事件ではなく軍事的緊張へ移行する恐れがあった
* よって、労働局は現場で可能な範囲の実力行使により逃亡を阻止する必要があった

橘は静かに言う。

「不在だったことは事実です。班長として、その責任は私にあります」

アルテミシアは一瞬だけ反応するが、止めない。橘がその責任を受けることを理解している。

金剛寺は、現場判断について「勝ちに行ったのではなく、逃がさないために居座った」と確認する。

### 3. 会見開始

アルテミシアが冒頭説明を行う。

内容は次の順。

1. 被害者保護と証拠確保が一定程度成功したこと
2. 国外勢力による人身売買網の橋頭堡を潰したこと
3. 介入班に死者と多数の負傷者を出したこと
4. 立野隊員の名を出し、職務遂行中に死亡したことを明言する
5. 遺族、負傷者、関係機関への謝意と謝罪
6. それでも足を止めないという労働局の意思

アルテミシアの言葉は静かで整っている。

ただし、読者には十二話の祈りの後遺症が残っていると分かる。彼女は穏やかに話しているが、内側の線引きが以前より鋭くなっている。

### 4. 法務部長への質問

記者が問う。

「海上臨検隊や国防軍に任せるべきだったのではありませんか」

法務部長が答える。

要点は、労働局が「完全制圧」を狙ったのではなく「遅滞行動」を行ったという切り分け。

答弁骨子。

```text
そのご指摘は、結果だけを見れば当然のものです。
ですが、当時の状況は極めて流動的でした。
国家警察は人質救出側への対応を優先しており、海上臨検隊も湾内の捜索と封鎖に即応していました。
国防軍CTRUの投入についても、要請から出撃、現着までにはどうしても時間を要します。

国家労働局が独力で排水ポンプ場を完全制圧しようとした、という理解は正確ではありません。
我々が選択したのは、逃亡経路を塞ぎ、証拠隠滅を遅らせ、国家警察および国防軍が到着するまでの時間を稼ぐための遅滞行動です。

仮にあの時点で待機を選んでいれば、関係者は小型艇で湾内へ出ていた可能性が高い。
さらに湾外の不審艦艇へ接続されれば、以後は刑事捜査ではなく軍事的緊張を伴う問題へ移行していた恐れがあります。

したがって当局は、現場で可能な範囲の実力行使をもって、逃亡を阻止する必要があると判断しました。
```

### 5. 金剛寺への質問

記者が現場の無謀さを問う。

金剛寺は感情を抑えつつ、現場指揮官として答える。

要点は、勝つための突入ではなく、逃がさないための足止めだったこと。

```text
現場判断としても、完全制圧は狙っていません。
逃がさないこと。燃やさせないこと。沈めさせないこと。
その三つです。
こちらの戦力で勝ち切れる相手ではないことは、最初から分かっていました。
```

ここで金剛寺は立野の名を出すか迷う。

出してもよいが、記者会見で美談化しない方がよい。

候補。

```text
立野は、任務を理解していました。
あいつだけじゃありません。あの場にいた全員が、何を止めるためにそこに残ったのかを理解していました。
```

### 6. 橘への質問

記者が橘の不在を突く。

「介入班の班長が不在の中、強行すべきではなかったのでは？」

さらに踏み込む。

「肝心な時にいないとは、なんとも気楽な……」

ここで会見場の空気が変わる。

アルテミシアの目がわずかに細くなる。質問をした記者は、その整った顔貌に浮かぶ穏やかな表情が、急に温度を失ったように感じる。

怜悧な氷の刃。

怒りではない。怒りならまだ人間の熱がある。それはもっと静かで、もっと澄んだものだった。相手の言葉を受け止め、意味を測り、どこを切ればよいかを正確に見定めている目だった。

法務部長は渋い顔をする。

金剛寺は痛ましげにアルテミシアを見る。総裁らしくない、と思う。祈りの影響なのか、橘に対する執着が以前より表に出ている。

ただし、橘が先に答える。

```text
不在だったことは事実です。
班長として、その責任は私にあります。
```

そこで一度、短く間を置く。

```text
ですが、現場にいた隊員たちは判断を誤っていません。
彼らは命令を待って死んだのではありません。
被害者を逃がさず、証拠を消させず、後続部隊が到着するまでの時間を稼ぐために、必要な任務を遂行しました。
```

橘は立野を英雄にしすぎない。

```text
立野は任務中に死亡しました。
その事実は、どんな言葉でも軽くなりません。
ですが、彼の死を、現場判断を貶める材料に使うことは許容できません。
```

この一言で、橘の班長としての線を見せる。

### 7. アルテミシアの反撃

会見の後半で、記者たちが「労働局の権限見直し」を問う。

アルテミシアが受ける。

ここで演説調になりすぎないようにする。声は澄んでいて、静か。ただし内容は重い。

骨子。

```text
我々は大きな損害を出しました。
勇敢な隊員の命と引き換えに、人身売買という度し難い犯罪ネットワークを白日の下に晒し、複数の証拠を手に入れました。

国外からのシンジケートにも似た勢力が、本邦に根を張り、橋頭堡を構築しつつありました。
その鼻先に、我々の血をもって痛打を加えたのです。

確かに、尊い命が失われ、介入班には多数の負傷者が出ています。
しかし、我々に悔いている時間はありません。

たとえ隊員が倒れようとも、それは我々が足を止め、眼前の被害者を見捨てる理由にはなりません。
そうあるべきだと、我々は意志を統一し、進むと決めたのです。
```

会見場が静まる。

アルテミシアは、記者たちの顔を一人ずつ見ている。

誰が質問したか。
誰が沈黙したか。
誰が隣の記者に目配せしたか。
誰が、あえて踏み込まなかったか。

そのすべてを記憶していく。

誰が敵で、誰が交渉可能で、誰を無害化すべきか。

ここで「無害化」は地の文で一度だけ使う。読者に、アルテミシアの内面が少し危うい方向へ傾いていることを示す。

橘は隣でその横顔を見る。

見慣れたはずの横顔が、その時だけ少し遠く見える。

### 8. 会見後

会見後、控室。

法務部長は疲れた顔で、会見の火消しは簡単ではないと告げる。

金剛寺は、立野の遺族対応と負傷者見舞いに向かう。橘も同行しようとするが、先にアルテミシアが呼び止める。

橘とアルテミシアの短い会話。

甘くはしない。互いに言葉を選びすぎて、必要なことしか言えない。

候補。

```text
「戻りました」
「ええ。おかえりなさい」
```

それだけでは足りないが、それ以上を言うべき場所でもない。

アルテミシアは橘の顔を見る。橘はいつも通りに見える。しかし、国外から急ぎ帰国した疲労と、立野の死を聞いた後の静けさがある。

橘は言う。

```text
「会見中、少し怖い顔をしていました」
```

アルテミシアは一瞬だけ目を伏せる。

```text
「そうですか」
```

橘はそれ以上追及しない。

```text
「総裁。次は負傷者のところへ」
```

アルテミシアは頷く。

```text
「はい。行きましょう」
```

二人は並んで歩く。ただし、橘はいつもの斜め後ろではなく、一歩だけ横に近い位置を歩く。

アルテミシアはそれに気づくが、何も言わない。

### 9. 幕引き

終盤は報告書と今後の処理。

* 人質救出作戦は成功
* 真船関連の供述と押収物は国家警察へ接続
* 梁瀬、新華月警備、港湾警備委託の再調査へ
* 瑞海系勢力の国内協力者の一部が摘発対象に入る
* ミラージュは逃げ切る
* レンシア通商連合評議会は労働局を叩きつつ、瑞海勢力排除の成果は利用しようとする
* 労働局強制介入班は一時的に戦力低下

最後は、立野の死亡通知か、負傷者病棟、もしくは空いた班長席・装備ラックで閉じる。

候補となるラストイメージ。

```text
強制介入班の装備庫に、立野のロッカーだけが閉じられたまま残っている。
誰かが片づけるには早すぎて、誰もそのままにしておくには重すぎる。
橘はその前で一度だけ足を止める。
だが、長くは止まらない。

幕は下りた。
次の幕の準備をする者だけが、まだそこに残っていた。
```

## 主な見せ場

1. 法務部長が「遅滞行動」として適法性を切り分ける
2. 金剛寺が現場判断を短く重く説明する
3. 橘が不在責任を受け、班長として部下の判断を守る
4. アルテミシアが会見で静かに反撃する
5. アルテミシアの「無害化」という内面語で変質の兆しを出す
6. 会見後、橘とアルテミシアの曖昧な関係を短く描く
7. 立野の死を美化せず、組織に残った欠損として閉じる

## 注意点

* 記者会見を長くしすぎると説明回になる。質問は三本程度に絞る。
* アルテミシアは怒鳴らない。静かに、相手の逃げ道を塞ぐ。
* 橘は感情的に反論しない。責任を受けたうえで、現場と部下を守る。
* 金剛寺は雄弁にしすぎない。現場の人間として短く重い方が効く。
* 立野の死は英雄化しすぎない。職務上の死として重く扱う。
* レンシア通商連合評議会は全悪ではなく、利害で動く構造として描く。
* ミラージュはここで倒さない。幕引きの外側に残す。

第十三話で第一期の事件はいったん閉じる。

ただし、以下を残す。

* ミラージュは逃走
* 瑞海系勢力は痛手を受けたが消えていない
* レンシア通商連合評議会は労働局への警戒を強める
* アルテミシアは祈りの後遺症で、敵味方の線引きが鋭くなっている
