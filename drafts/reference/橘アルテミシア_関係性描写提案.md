# 橘×アルテミシア　関係性描写の提案

## 現状分析

### 設定資料で語られていること
設定資料には非常に豊かな感情の地層がある。橘のアルテミシアへの「歪んだ献身」「自分から逃げるための避難所」、アルテミシアの橘への「罪悪感・救済欲・執着」。局内では「公然の秘密」。恋人でも上司部下でもない曖昧な距離。

### 公開済み原稿で描かれていること
ほぼ全てが業務上のやり取り。二人の関係性は「言わないこと」「省略されること」で間接的に示されている。

- **25話**が最も近い距離の描写。「無茶はしないでくださいね」「そのための直通回線ですので」。橘がアルテミシアの癖（眉間の皺を指で揉む）を通信越しに想像できること。
- **21話**では尋問をシームレスに連携する。橘が言いかけた台詞をアルテミシアが引き取る。
- **2話**では「言葉を交わさないが、もう共有しているように見えた」。

### ギャップ
設定資料の感情の厚みに対して、原稿での描写は「有能な連携」に偏っている。二人の曖昧な距離を読者に感じさせる、もう少し肌理の細かい描写が足りない。

---

## 方針

- **甘くしない。** ロマンスではなく、関係の質感を見せる。
- **業務の隙間**に差し込む。新しいシーンを丸ごと作るのではなく、既存の流れの中に数行〜数段落の描写を挿入する形が馴染む。
- **曖昧さを維持する。** 読者に「これは何なのか」と思わせる距離感。名前をつけさせない。
- **他者の目線**を活用する。二人の当事者視点だけでなく、ナディアや項、神山の目から見た「距離」を描く。

## 提案一覧

### 提案A：距離の描写（身体的距離感）

橘はアルテミシアの近くに立つとき、他の誰とも違う位置を取る。護衛として近く、補佐官として控え、だがそのどちらとも微妙にずれた位置。この「定位置」を繰り返し描写することで、言語化されない関係の輪郭を浮かべる。

**挿入候補：会議室・CIC・作戦前のブリーフィング等**

```
橘はアルテミシアの斜め後ろに立った。護衛としては少し遠く、補佐官としては少し近い。
それがこの男の定位置だった。誰に言われたわけでもない。ただ、いつからかそこに立つようになった。
```

あるいは、他者視点で：

```
ナディアは画面から目を上げた。橘がいつもの位置に立っている。
アルテミシアの斜め後ろ。護衛として近く、部下として遠い、名前のつかない距離。
ナディアはそれ以上考えることをやめた。考えたところで、あの二人の間にある何かに名前をつけることは、おそらく本人たちにもできない。
```

---

### 提案B：通信を切る前の間（沈黙の描写）

25話の通信シーンが良い前例。通信を切る直前の一瞬の間、あるいは切った後の数秒の余韻を描写する。「まだ何か言うべきことがあったような気がする」「だが言葉にならない」という空白。

**挿入候補：橘がヴェルフラードから報告する場面、作戦前後の通信**

```
通信が切れた。
橘はしばらくそのまま立っていた。耳の奥に、アルテミシアの声の残響がある。言い忘れたことがあるような気がした。
だが、考えても何も浮かばなかった。何も浮かばないことにも、もう慣れていた。
```

アルテミシア側：

```
回線が落ちた。画面が暗くなる。
アルテミシアは端末を伏せた。橘の声を聞くたびに、あの義体の継ぎ目を思い出す。
自分がそうさせたわけではない。だが、自分が止められなかった。その区別は、年を追うごとに曖昧になっていく。
```

---

### 提案C：聞かないこと（不問の信頼／不問の罪悪感）

橘がクラウディアの工房から戻った後、アルテミシアが義体の状態を聞かない。聞かないのは信頼なのか、聞けば自分の罪悪感に触れるからなのか。橘もまた、報告しない。報告すれば彼女が気にすることを知っているから。

**挿入候補：23話〜24話の前後、あるいは今後の義体メンテ関連**

```
「お帰りなさい。ゆっくり休めましたか？」

アルテミシアは義体のことを聞かなかった。
クラウディアのところへ行ったことは知っている。何を交換し、何を較正し、どれだけ消耗していたかも、報告を読めばわかる。
だが聞かない。橘もまた、言わない。
どちらが先にそうし始めたのかは、もう覚えていない。
```

---

### 提案D：他者の目（ナディア、項、神山の視点）

二人の関係を最も効果的に描くのは、第三者の視点。特にナディアは近い位置にいて、かつ観察力がある。

**挿入候補：CICシーン、会議後の廊下、作戦前の待機時間**

ナディア視点：
```
作戦卓を挟んで向かい合う二人を見ていると、ナディアは時々わからなくなる。
アルテミシアが橘を信頼しているのは疑いない。橘がアルテミシアのために動くことにも疑いはない。
だが、それだけで説明できるなら、あの二人の間にあの種の沈黙は生まれない。
言葉の少なさが信頼の証なのか、言葉にできないものを避けているだけなのか。
ナディアにはわからなかった。わからないままにしておくのが、おそらく正しい。
```

項宗梧視点（もう少し軽い温度で）：
```
項は煙草に火をつけながら、CICを出ていく橘の背中を見ていた。
あの男は、総裁のためなら壊れかけの義体でも走る。それは知っている。
知っていても、口にはしねぇがなぁ、と項は思う。言ったところで、本人は否定するだろう。否定の仕方で全部ばれるのに。
```

神山視点（外部者の距離感で）：
```
神山は労働局の会議に何度も同席してきたが、橘とアルテミシアの距離感だけは慣れなかった。
上司と部下にしては近すぎる。恋人同士というには、あまりに乾いている。
だが何より気になるのは、あの二人が互いを見る時の目だった。見ているのに、何かを見ないようにしている。その不自然さだけが、神山にはわかった。
```

---

### 提案E：橘の習慣（無意識の献身の痕跡）

橘が無意識にアルテミシアのためにしている小さなこと。お茶を淹れる、書類の順序を整える、会議室の温度を調整する。本人は任務の延長としか思っていない。だが客観的に見れば、それは「気遣い」以外の何でもない。

**挿入候補：日常業務シーン**

```
橘は会議資料を並べ替えた。アルテミシアが読む順に。
別に頼まれたわけではない。ただ、彼女が資料を手に取る時の癖を知っている。結論が先、根拠が後。法的論点は左、現場状況は右。
こういう作業を、橘は任務だと思っている。任務だと思っていなければ、自分がなぜここまで知っているのかを考えなければならない。
```

---

### 提案F：アルテミシアが橘の義体に触れる／触れない

最も繊細なポイント。アルテミシアが橘の義体化された部分に、無意識に目を向ける。あるいは触れそうになって止める。あるいは一度だけ触れて、何も言わない。

**挿入候補：二人きりになる短い瞬間（廊下、エレベーター、作戦前の一瞬）**

```
会議が終わり、全員が退室した。
アルテミシアは立ち上がりながら、橘の右手を見た。義体と生身の境界線が袖口からわずかに覗いている。
視線はすぐに外れた。一秒にも満たない。
橘は気づいていないふりをした。彼女がそこを見る時の表情を、知っている。罪悪感でも同情でもない、もっと厄介な何かだ。
だが橘はそれに名前をつけない。つければ、自分の側にも名前をつけなければならなくなる。
```

## 挿入優先度

| 優先度 | 提案 | 理由 |
|---|---|---|
| 高 | A（距離） | 繰り返し使える基盤描写。地の文に数行で済む |
| 高 | D（他者の目） | 二人の外側から関係の輪郭を描ける。視点変化の自然な挿入点が多い |
| 中 | B（通信の間） | 既存の通信シーンに追加しやすい。25話の延長線上 |
| 中 | F（義体への視線） | 最も感情の密度が高い。使いすぎると甘くなるので1-2回 |
| 低 | C（聞かないこと） | 効果的だが、描写機会が限られる |
| 低 | E（無意識の習慣） | 日常描写が少ない作品特性上、挿入点が少ない |

---

## 補足：やらないほうがいいこと

- 二人きりの「甘い空気」のシーンを作ること。この作品の空気に合わない。
- どちらかが感情を言語化すること。曖昧さが壊れる。
- 他者が二人の関係を明確に名指すこと（「あの二人、付き合ってるの？」等）。下品になる。
- 回想で義体化以前の関係を詳しく描くこと。今の関係が「変質後」であることが重要なので、以前を見せすぎると比較対象ができてしまう。
