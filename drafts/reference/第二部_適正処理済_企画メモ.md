# 第二部企画メモ：適正処理済

## 位置づけ

第二部は第一部からおよそ一年後を想定する。

排水ポンプ場で大きな損害を受けた強制介入班は、完全ではないものの実働可能な状態まで回復している。第一部が「人間を商品として扱う構造」を扱ったのに対し、第二部は「人間、残土、事故、責任をすべて適正処理済として捨てる構造」を主題とする。

仮題は「第二部　適正処理済」。

## 第二部の主題

親和鉱石産業の裏側にある、産業廃棄物処理、不正助成金、不法投棄、不法就労、労災隠蔽を主軸にする。

単発の環境犯罪ではなく、企業群が日常業務の一部として犯罪を制度内へ押し込んでいる構造を描く。

第一部の国外勢力、人身売買ネットワーク、瑞海の動きは背景として残す。ただし第二部の主敵は瑞海ではなく、オルセア国内の企業群とその周辺にいる危機管理・下請け暴力である。

## 導入事件

とある入江に、海洋生物の死骸が多数漂着する。

資源環境監督庁の環境汚染防止部、調査分析・監視部が分析した結果、親和鉱石採掘時に生じる廃液または未処理残土由来の汚染である可能性が浮かび上がる。

魚体、鰓の付着物、海水、沢水、潮だまりの水を分析したところ、親和鉱石採掘残土または未処理廃液由来の成分が検出される。海流、風向、沿岸地形、潮位をもとに推測地点を絞り込むと、カルミア鉱山とその処理系統が第一候補として浮かび上がる。

資源環境監督庁は不法投棄の現場を押さえようと動くが、排出記録、搬出記録、処理済みサンプル、許認可は書類上すべて整っており、黒菱鉱業株式会社の尻尾を掴めない。

今回の案件は、第一部終盤のような急迫した人命救助案件ではない。したがって労働局は、武力を伴う強制介入ではなく、鉱山における作業環境測定結果の確認として入る。

労働局は、原子力発電所、化学薬品の製造・取扱施設、鉱山、親和鉱石採掘・精製施設のような、危険で健康被害が生じやすい事業場に対し、定期的な作業環境測定を義務づけている。事業者は測定結果、改善措置、保護具支給記録、健康診断記録、教育記録を提出しなければならない。

加えて、測定結果の改竄、健康被害の隠蔽、労災申告の不自然な欠落が疑われる場合、労働局は抜き打ちの立入検査を実施できる。

資源環境監督庁は、黒菱の不法投棄疑惑を環境側から追うには証拠が弱い。そこで、作業環境測定監督、労働安全衛生、下請け作業員の配置、健康被害、労災隠蔽の線から国家労働局へ協力を打診する。

## 黒菱鉱業株式会社

カルミア鉱山の採掘権を有する鉱業会社。

廃棄物管理規制基本法上の許認可は通っており、書類上は残土も廃液も適正処理済となっている。

親和鉱石関連の採掘権、残土処理、再資源化事業、港湾輸送に関与しており、レンシア通商連合評議会の資源部門と深く結びついている。

黒菱に踏み込むことは、一企業への調査ではなく、オルセアの企業群の太い血管へ針を刺すことに近い。

## レンシア通商連合評議会

首都圏企業の利益調整団体を名目とする、オルセア国内最大級の企業連合体。

物流、港湾、資源流通、警備、金融に強い影響力を持つ。国家機関の内部にも縁深い者、要するに抱き込まれている者がいる。

政府側の会議体とは名称を分ける。政府の中枢機関は「連邦行政会議」、企業連合体は「レンシア通商連合評議会」とする。本文で単に「評議会」と呼ぶ場合は、原則としてレンシア通商連合評議会を指す。

## 不法投棄と固定化残土

親和鉱石採掘残土は、適正に処理する場合、固化剤を混和して固定化残土として扱う。

固定化とは、汚染物質を消すことではない。有害金属化合物を除去するのではなく、溶け出しにくい形で封じ込め、圏外への流出を抑える処理である。

酸化マグネシウム系の固化剤、酸抽出洗浄、中和処理などが使われる。固化剤は高価だが、薬剤混和による固定化は抽出洗浄より早く、廃液処理の負担を減らせる。そのため助成金の対象になっている。

黒菱側の不正は以下の組み合わせで行われる。

- 処理済みサンプルだけを正規に作る。
- 実際の大量残土には固化剤を使わない、または規定量を大きく下回る量しか使わない。
- 処理済み残土として助成金を受給する。
- 固定化残土名義で限定用途の再利用材として処理したように見せる。
- 未処理残土は山中、沢、港湾工事、浚渫土砂、仮設路盤材などに紛れ込ませて捨てる。

黒菱から提出された排出残土サンプルは、庁のデータベース上の処理済み値と一致する。

一方で入江の魚体、鰓の付着物、水検体からは、固化剤由来元素のピークも、酸抽出洗浄と中和処理の痕跡もほとんど見られない。よって、汚染源は未処理残土または未処理廃液の流出である可能性が高い。

## 資源環境監督庁

国内資源、環境汚染、採掘廃棄物、再資源化事業を監督する官庁。略称は資源庁。

第二部では環境汚染防止部と調査分析・監視部が関与する。

資源環境監督庁は汚染と産出元の推定まではできるが、書類上の排出記録が正当であるため、黒菱への強制調査には踏み込みにくい。そこで労働局の作業環境測定監督、労働安全衛生、下請け作業員管理の権限を必要とする。

## 橘とエリカの調査同行

橘とエリカはカルミア鉱山の作業環境測定結果を確認するため、抜き打ちの立入検査に向かう。

鉱山は一般道から外れた山奥にあり、携帯端末の電波が入らない。現地で採取した測定値、写真、聴取メモ、作業環境測定の再確認データは、帰局後に同期するしかない。

この「まだ庁内サーバーへ同期されていない」状態が、襲撃側にとって最後の猶予となる。

鉱山管理者は、雨で未処理残土が流出したことにより行政に怪しまれたと悟り焦る。処理済みとして提出したサンプルとは異なり、実際に投棄した残土は未処理である。持ち帰られれば、固化剤の痕跡も酸洗浄の痕跡も出ない。

違法投棄だけなら担当者の切り捨てで済む可能性がある。しかし親和鉱石採掘残土の未処理投棄は、環境犯罪、助成金詐欺、労働安全衛生違反、虚偽報告、組織犯罪へ接続される。

## 襲撃の理由

レンシアは日常的に治安部隊と武装勢力が撃ち合うほど荒廃した社会ではない。

そのため、法執行機関を正面から襲撃する行為は極めて重い。黒菱や評議会本体が直接手を出すことはできない。

襲撃の動機は、橘とエリカの殺害そのものではなく、持ち帰られる前の証拠回収と事故処理である。

主な回収対象は以下。

- 現地採取した残土サンプル。
- エリカの分析メモ。
- 車載端末と携帯端末の記録。
- 橘の現場写真、映像、位置情報。
- 鉱山管理者との会話記録。

正式に労働局と資源環境監督庁の記録へ同期されれば遅い。山道での事故、反新資源活動家による襲撃、武装強盗などに偽装するには、同期前に奪う必要がある。

## ルプス

評議会にも、後ろ暗い仕事を請け負う連中はいる。

企業の不祥事を揉み消す。証人を黙らせる。書類に残らない荷を動かす。そういう危機管理会社や下請けは珍しくない。

だが、本職の法執行機関の一員を襲撃するとなれば話は別である。発覚時の火の回りが早すぎるため、評議会系の危機管理会社も直接名前が出る形では動きたがらない。

そこで使われるのが、切り離しやすい傭兵である。

要するに野良犬。

ただし、野良犬の中にも狼が混じることがある。

それが「ルプス」と呼ばれるチームである。

ルプスは、もとは華栄の法執行機関に所属していた特殊捜査部隊だったらしい。潜入、追跡、非公式拘束、証拠回収を得意とし、捜査のためという名目で法の外縁を踏み越えてきた。

成果は出したが、素行が悪すぎた。

押収物の横流し、容疑者への過剰暴行、証拠の差し替え、非公式な脅迫。組織が抱え続けるには危険すぎ、部隊は解体。主要隊員は不名誉除隊となった。

現在は雇い主を変え、国境を越え、ルプスという名前で切り離し可能な実働チームとして動いている。

元法執行機関のため、相手の弱点を知っている。

- 公用端末の同期タイミングを狙う。
- 証拠保全の手順を知っている。
- 通信、タイヤ、逃走経路、運転席視界から潰す。
- 殺害より証拠回収を優先する。
- 事故偽装の作法を知っている。

## 橘の私物火器：ビショップ・アーマメント《ニンジャ》

ビショップ・アーマメント製の秘匿携行型PDW。

MP5KやP90に近い思想で作られており、精密射撃には向かない。短い銃身と小型化された機関部は、秘匿性、携行性、取り回しを優先した結果である。

本来の用途は、敵を制圧しきることではない。

室内戦や至近距離で相手の頭を下げさせ、その数秒の間に護衛対象を危険範囲から離脱させることに重きを置いている。威力、精度、継戦能力を犠牲にして、秘匿性、即応性、離脱支援能力を得た火器である。

橘の《ニンジャ》は私物であり、実弾火器、未申請、労働局の装備管理台帳にも載っていない。ガンケースに収められてはいるが、常時車載されている時点で完全に違法である。

介入班の少なくないメンバーが、自衛用に秘匿火器や未申請装備を持っている。公には存在しない。上司も聞かない。仲間も見ないふりをする。

それだけ恨みを買う仕事である。

アルテミシアは知らないふりをしている。橘も、知られていないふりをしている。

## 労働局管理登録装備 LMシリーズ

LMは国家労働局内部の武装・制圧装備管理登録符号であり、メーカー型番ではない。

初期登録装備であるLM-1からLM-3までは、拳銃、鎮圧用スタンバトン、特殊警棒といった近距離制圧装備が中心であり、労働監督官庁としての警察比例の原則を強く意識した構成だった。

その後、登録IDを持たない不法就労者の強制労働、武装警備会社による妨害、高度自律機械の違法運用、国外勢力の関与が顕在化するにつれ、従来装備では現場の安全を確保できなくなった。

その結果として追加されたのが、電磁射出式カービンであるLM-4と、対器材・対機械精密無力化を目的とするLM-5である。

LMシリーズの番号は、労働局がどのようにして監督官庁から強制介入機関へ変質していったかを示す制度上の痕跡でもある。

| 登録名 | 種別 | 用途 |
|---|---|---|
| LM-1 | サイドアーム | 近距離用拳銃。護身、近距離対応、最終防衛 |
| LM-2 | 鎮圧用スタンバトン | 暴徒鎮圧、拘束補助、通電制圧 |
| LM-3 | 特殊警棒 | 非通電式の物理打撃装備。電子装備に頼れない環境や通電が危険な対象に用いる |
| LM-4 | 電磁射出式カービン | 介入班の標準火器。和富銃器製作所製 Magnetic Projector Type Carbine |
| LM-5 | 大口径狙撃銃 | 対器材、対機械、重火器、通信設備などの精密無力化 |

## LM-4

和富銃器製作所製の法執行機関向け電磁射出式カービン。

メーカー分類は「Magnetic Projector Type Carbine」。国家労働局では管理登録名「LM-4」として採用されている。

主弾種はスタンニードル弾。短針状の制圧針と通電用電極を樹脂製サボット内に収め、電磁加速で射出する。

火薬式薬莢を必要としないため、射撃後に空薬莢は排出されない。ただし、着弾後には破断したサボット片が残る。

弾薬マガジンとは別に、親和鉱石系の積層高容量小型バッテリーパックを使用する。マガジンとバッテリーはいずれも迅速な交換を前提に設計され、操作系は左右両対応のアンビ設計となっている。

弾種は一定範囲で変更可能であり、殺傷弾の射出にも対応する。ただし事故防止のため、弾薬マガジンの弾種情報と本体側セレクターの設定が一致しなければ射撃できない。弾種切り替え時には、射手がセレクターを明示的に操作し、火器管制側でも弾種合致を確認する必要がある。

火薬式銃器のような排莢機構は持たないが、給弾不良やサボット破損に備え、装填済み弾体を強制排出するためのクリアリングレバーを備える。重度の異物混入時には、ヒンジ式の上部整備カバーを開放し、給弾路と加速室を露出させて復旧作業を行う。

現場では、給弾停止や射出停止もまとめて「ジャム」と呼ばれる。

- 第二部冒頭は、海洋生物の死骸漂着と資源環境監督庁の分析から始める。
- 労働局への接続は、黒菱の作業環境測定結果、下請け作業員の健康被害、労災隠蔽から行う。
